# Orbital Command — sistema de identidade

## Ideia central

O símbolo representa três fontes em órbita de um mesmo núcleo: **sinais**, **pessoas** e **automações**. A marca deve parecer uma central operacional confiável, não uma interface de ficção científica decorativa.

## Marca

- `ORBITAL` é o nome principal, em caixa alta e peso forte.
- `COMMAND` usa menor escala e maior espaçamento.
- O símbolo funciona isolado em avatar, favicon e produto.
- Órbitas representam integração; o núcleo representa decisão.

O SVG oficial está em `apps/web/public/orbital-command-mark.svg`.

## Paleta

| Token | Cor | Uso |
|---|---|---|
| Void | `#050810` | fundo principal |
| Surface | `#0A101C` | superfícies |
| Signal Cyan | `#5DE3FF` | ação, dados ao vivo |
| Command Blue | `#4C7DFF` | navegação e estrutura |
| Automation Violet | `#9B7BFF` | automações |
| Stable Green | `#43DFA0` | operação normal |
| Incident Red | `#FF5E7D` | incidentes críticos |

## Linguagem visual

- bordas finas e baixo contraste para estruturar sem poluir;
- tipografia monoespaçada apenas em dados e estados;
- brilho reservado para sinais vivos e itens críticos;
- densidade de painel empresarial com hierarquia clara;
- movimento orbital lento, nunca competindo com alertas.

## Voz

Precisa, curta e orientada a ação. O produto diz o que aconteceu, por que importa, quem assumiu e qual ação foi executada.
